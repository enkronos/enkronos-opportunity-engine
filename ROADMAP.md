# Roadmap

## Phase 1 — Foundation

- Replace repo identity and package surface with Opportunity Engine
- Add the six core modules
- Introduce `strategy.yaml` as the strategic source of truth
- Remove the active CV-generation runtime path

## Phase 2 — Qualification

- Expand opportunity ingestion beyond manual JSON
- Add source adapters for inboxes, feeds, and curated lists
- Improve classification coverage for advisory, partnership, investor, and pilot motions

## Phase 3 — Strategic Reasoning

- Deepen scoring prompts and factor explanations
- Add richer evidence capture for each score
- Support profile-specific scoring presets

## Phase 4 — Positioning And Outreach

- Add better message variants by channel and opportunity type
- Introduce one-page opportunity memo generation
- Add contact strategy recommendations

## Phase 5 — Pipeline Intelligence

- Track next actions, owners, and follow-up dates
- Add summary dashboards and weekly review outputs
- Support pipeline exports for CRM interoperability

## Phase 6 — Execution Layer

- Connect outreach to real delivery channels
- Add intro routing, sequencing, and response logging
- Integrate with broader agent systems where useful, without bloating the core
